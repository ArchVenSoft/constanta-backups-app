Constanta backups

A personal backup tool for one household's own computer.

Constanta backups copies the data of a small, self-hosted office application to the user's own Google Drive once a night. Every file is encrypted on the user's computer before it is uploaded, so Google stores only scrambled data.

What it accesses

It asks Google only for the narrowest Drive permission, drive.file: it can see and change only the files it created itself. It cannot read, list or change any other file in the user's Drive.

Who uses it

It is not a public service and has no sign-up. It is used by one household for its own backups.
