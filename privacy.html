Privacy policy

Constanta backups · last updated 12 November 2026

What data the app handles

The app runs only on the user's own computer. Each night it copies that computer's application data to the user's own Google Drive. The data is encrypted on the computer before upload, with a passphrase only the user holds.

What Google access it uses

It uses the Google Drive permission drive.file, which lets it create files and see or change only the files it created. It does not read, list, copy or change any other file in the user's Drive, and it uses no other Google service.

What the developer receives

Nothing. The app sends no data to the developer or to any third party. There are no analytics, no tracking and no advertising. Data obtained from Google is used only to store and restore the user's own backups, and it is never sold, shared or used for any other purpose.

How to remove access

The user can remove the app's access to Google Drive at any time at myaccount.google.com/permissions. The backup files stay in the user's Drive until the user deletes them.
